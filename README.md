# Performance Tracker demo

Navigable sample of four Performance Tracker ideas for the October 14 walkthrough.

The home screen lets you open each idea and use it. Numbers are generated sample data for 24 domains through October 8, 2026. This is not a live Cocolytics workspace.

- Domain ledger: one row per domain, column picker, grouping, load more
- Band board: top, middle, and bottom with the reply rate if only the top group sent
- Day grid: reply rate by domain and day
- Provider desk: Google, Microsoft, SMTP, and MilkBox or ScaledMail, with the previous window in percentage points

```bash
npm install
npm run dev
```
